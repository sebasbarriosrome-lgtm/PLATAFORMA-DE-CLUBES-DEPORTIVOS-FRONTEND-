Instalación y despliegue del proyecto
Este proyecto está compuesto por:

Frontend: React + Tailwind CSS

Requisitos previos
Asegúrate de tener instalado:

Node.js ≥ 18
npm o yarn
Git

Instalación del Frontend (React + Tailwind)

1. Clonar el repositorio del frontend
   git clone https://github.com/sebasbarriosrome-lgtm/PLATAFORMA-DE-CLUBES-DEPORTIVOS-FRONTEND-.git
   cd PLATAFORMA-DE-CLUBES-DEPORTIVOS-FRONTEND-
2. Instalar dependencias
   npm install
3. Ejecutar el proyecto
   npm run dev
   El frontend quedará disponible en:
   http://localhost:5173
